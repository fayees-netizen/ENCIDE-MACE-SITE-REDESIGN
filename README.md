# ENCIDE MACE – UI/UX Redesign

A modern redesign of the official **ENCIDE MACE** website, focused on improving user experience, visual design, and responsiveness while preserving the original purpose and identity.

**Original Website:** https://www.encide.in/

## Features

- Modern and responsive UI
- Interactive hero section
- Smooth GSAP animations
- Three.js 3D elements
- Redesigned navigation and layouts
- Team, Events, Testimonials, FAQ, and Contact sections
- Mobile-friendly design
- Clean, accessible interface

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Tailwind CSS
- GSAP
- Three.js

## Disclaimer

This is an independent UI/UX redesign created for educational and portfolio purposes. It is not the official ENCIDE MACE website.
